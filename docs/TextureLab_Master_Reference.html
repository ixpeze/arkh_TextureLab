ARKH TextureLAB

The definitive high-velocity workstation and headless pipeline runner for PBR texture authoring, channel packing, format conversion, and set validation.

1. Executive Summary & Core Philosophy

ARKH TextureLAB is a native Windows desktop workstation and automated headless CLI runner created to solve the friction of channel packing, format conversion, normal space alignment, and texture set validation in modern game development.

100% Pure Native Rust ⚡

Built with eframe 0.31, egui 0.31, and egui_dock 0.16. Zero Python runtime, zero electron bloat, and ~6 MB standalone binary.

Topological Reactive DAG ⚙️

Deterministic execution via Kahn's topological sort with cycle detection, dirty-subgraph propagation, and generation-counter debouncing.

Dual Binary Pipeline 🚀

Includes both the full visual workstation (texturelab.exe) and the headless runner (texturelab-cli.exe) for build automation and CI/CD.

Workspace Governance Standard
The release binary is strictly maintained in target\release\texturelab.exe. In accordance with project architecture rules, no duplicate release directories are maintained in the repository root.

2. System Architecture & Engineering Deep-Dive

TextureLAB decouples immediate-mode rendering from asynchronous background DAG evaluation, guaranteeing 60 FPS viewport fluidity even while re-sampling large 4K and 8K image rasters.

graph TD Client["Canvas & User Input"] -->|Dirty Param / Wire| History["HistoryStack (100-step Buffer)"] History --> Evaluator["AsyncEvaluator (Worker Thread)"] Evaluator --> Compiler["GraphCompiler (Kahn's Topo Sort)"] Compiler --> Schedule["Topological Evaluation Schedule"] Schedule --> RayonPool["Rayon ThreadPool (SIMD Compute)"] RayonPool --> Cache["Memoized SharedTextureBuffer Cache"] Cache --> Viewport["2D Viewport & Preview Repaint"] Cache --> Drawer["Export Textures Pipeline"]

Memory Architecture & Zero-Copy Smart Pointers

Image rasters are represented by TextureBuffer, backed by contiguous image::RgbaImage byte arrays. Node interconnections pass reference-counted SharedTextureBuffer (Arc<TextureBuffer>) handles, ensuring split operations and passthrough reroute nodes execute with zero memory duplication.

5. Canvas Navigation & Unreal-Standard Controls

Camera control, node spawning, and wire manipulation follow Unreal Engine Material Editor conventions:

Mouse Navigation
  • Right-Click Drag: Infinite canvas panning.
  • Mouse Wheel: Smooth zoom centered at cursor position.
  • Right-Click Tap: Context fuzzy search palette at cursor.
  • Alt + Click: Sever wire or disconnect pin.
  • Double-Click Wire: Insert inline Reroute pin.
  • Left-Click Drag: CAD-style box marquee select.
Two-Way Wire Routing & Auto-Wiring

Drag wires from Output-to-Input OR Input-to-Output. Releasing a wire over empty canvas automatically opens the search palette; selecting any node creates it and connects the origin wire to the most compatible slot.

Step-by-Step Production Tutorials

Tutorial 1: Packing a 4K Unreal Engine 5 ORM Texture

Convert loose source textures into Epic Games standard BaseColor, Normal, and ORM maps:

1
Drag & Drop Ingestion

Drag Albedo.png, Normal_GL.png, Roughness.png, Metallic.png, and AO.png from Windows Explorer directly onto the TextureLAB canvas. Nodes are instantiated with PBR role badges automatically.

2
Spawn Channel Combiner

Hold C or P and Left-Click on empty canvas. A ChannelCombine node appears.

3
Wire the ORM Sockets

Connect AO.R → Combine.R
Connect Roughness.G → Combine.G
Connect Metallic.B → Combine.B

4
Invert Green for DirectX Normal Space

Hold N and click to spawn NormalFlipGreen. Connect Normal_GL to it to satisfy Unreal's -Y normal format.

5
Export via Drawer (Ctrl+E)

Press Ctrl+E, select the Unreal Engine 5 preset, verify the health badge is green, and click "Export Textures to Disk".

13. Troubleshooting & FAQ

Why doesn't Backspace delete nodes?
To eliminate accidental node deletion while editing parameter fields or file paths, Backspace is intentionally decoupled from node deletion. Use the dedicated Delete key.
Can TextureLAB pack 8K textures smoothly?
Yes. TextureLAB uses Rayon parallel chunk processing across contiguous scanlines, processing full 8K multi-channel packing passes within 1.5–2.5 GB of RAM in under 500 ms.
